# Family Monthly Review — V3 Phase 1

Family Monthly Review merangkum jumlah catatan rutinitas, momen perkembangan,
kunjungan/vaksinasi, Family Check-in, dan Development Goal untuk satu bulan.
Setiap angka dibandingkan dengan bulan kalender sebelumnya sebagai selisih
jumlah pencatatan saja.

Respons tidak memuat caption Memory Journal, judul/catatan Goal, isi Check-in,
nama obat, diagnosis, notes, dokter, atau klinik. UI tidak memakai label
"lebih baik" atau "lebih buruk" karena frekuensi pencatatan bukan ukuran kondisi
anak maupun kualitas pengasuhan.

Fitur ini read-only, tidak membuat tabel baru, dan tidak membutuhkan scheduler.
Semua query dibatasi tepat pada bulan yang dipilih dan bulan pembanding.
